> **Solus** is an open-source, 100% offline Android application that runs state-of-the-art Generative AI models (DeepSeek R1, Gemma 3, Qwen 2.5, Llama 3) directly on your device with zero cloud tracking.

- 🔒 **100% Offline & Private:** Conversations and history never leave your phone.
- ⚡ **Multi-Runtime Engine:** Powered by LiteRT, MediaPipe GenAI, and native `llama.cpp` JNI bindings.
- ✨ **Dynamic Glassmorphism UI:** Jetpack Compose + Haze real blur with dynamic model accent themes.
